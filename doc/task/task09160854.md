# HFS 自动 Reactor 短验证任务

## 0. 目标与时间预算

**唯一目标**：验证库在不提供显式 reactor 配置时，能按 VM 在线 CPU 数量自动选择拓扑，并确认真实 NVMe 数据面没有明显回归。

- 总墙钟预算：**3–5 分钟**；超时立即停止。
- 后端固定：VM 内真实 NVMe，`config/hfs_nvme.json`、`HFS_BDEV_NAME=Nvme0n1`、PCI BDF `0000:0b:00.0`。
- 只做一次短性能 sanity，不形成新的正式性能基线。
- 不做 A/B 矩阵、重复取 median、adaptive/ticket/allocator/metadata 等扩展验证。

## 1. 显式 Reactor 设置必须去掉

本任务所有命令都必须在**没有显式 reactor 设置**的环境下执行：

- 不设置、不导出 `HFS_DATA_REACTORS`、`HFS_DATA_REACTOR_CPUS`、`HFS_OWNER_REACTOR_CPU`、`HFS_REACTOR_PIN`。
- 不设置任何 `HFS_BASELINE_*` 拓扑变量。
- 不使用 `taskset` 或其它 CPU 绑核参数；让库根据在线 CPU 数量自动匹配。
- 每个进程启动前清除可能继承的变量：

```bash
unset HFS_DATA_REACTORS HFS_DATA_REACTOR_CPUS HFS_OWNER_REACTOR_CPU HFS_REACTOR_PIN
unset HFS_BASELINE_TOTAL_REACTORS HFS_BASELINE_DATA_CPUS HFS_BASELINE_APP_CPUS
```

## 2. VM 前置检查（约 20 秒）

```bash
cd /root/code/HFS_BASE_SPDK
RUN=/mnt/hfs-data/task09160854
mkdir -p "$RUN"

test "$(readlink -f /sys/bus/pci/devices/0000:0b:00.0/driver)" = \
  /sys/bus/pci/drivers/uio_pci_generic
test "$(sysctl -n vm.nr_hugepages)" -ge 1024
test -z "$(pgrep -x fio || true)"
test -z "$(pgrep -x spdk-hfs || true)"
getconf _NPROCESSORS_ONLN | tee "$RUN/online_cpus.txt"
```

若 NVMe 未绑定、hugepages 不足或存在残留进程，停止任务，不输出性能结论。

## 3. 编译（约 1–2 分钟）

```bash
make -B app lib
```

编译失败即停止。

## 4. 自动拓扑探针（约 10 秒）

```bash
RUN=/mnt/hfs-data/task09160854
env -u HFS_DATA_REACTORS -u HFS_DATA_REACTOR_CPUS \
  -u HFS_OWNER_REACTOR_CPU -u HFS_REACTOR_PIN \
  -u HFS_BASELINE_TOTAL_REACTORS -u HFS_BASELINE_DATA_CPUS \
  -u HFS_BASELINE_APP_CPUS \
  LD_PRELOAD=build/lib/libhfs.so \
  HFS_CONFIG_PATH=config/hfs_nvme.json HFS_BDEV_NAME=Nvme0n1 \
  HFS_FORMAT=1 HFS_AUTO_MKDIRS=/verify \
  HFS_LOCK_PATH=/mnt/hfs-data/task09160854/auto.lock \
  python3 - <<'PY'
import os
import time

os.makedirs('/hfs/verify', exist_ok=True)
fd = os.open('/hfs/verify/reactor-probe', os.O_CREAT | os.O_RDWR, 0o600)
os.write(fd, b'probe')
os.fsync(fd)
os.close(fd)
time.sleep(1)
PY

grep -R -h "reactor topology:" /var/log/hfs 2>/dev/null | tail -1 | tee "$RUN/reactor_topology.log"
```

按源码策略验收：

```text
online_cpus = 1: data=0, total=1
online_cpus >= 2: data=min(4, max(1, floor(online_cpus/4))), total=1+data
```

当前 VM 为 8 vCPU 时应看到 `online_cpus=8 total=3 data=2 source=auto`。日志缺失、`source` 不是 `auto` 或数量不符合公式即失败。

## 5. 真实 NVMe 快速正确性回归（约 1 分钟）

```bash
env -u HFS_DATA_REACTORS -u HFS_DATA_REACTOR_CPUS \
  -u HFS_OWNER_REACTOR_CPU -u HFS_REACTOR_PIN \
  -u HFS_BASELINE_TOTAL_REACTORS -u HFS_BASELINE_DATA_CPUS \
  -u HFS_BASELINE_APP_CPUS HFS_BDEV_NAME=Nvme0n1 \
  bash scripts/db/posix_contract_test.sh \
  build/lib/libhfs.so config/hfs_nvme.json \
  /mnt/hfs-data/task09160854/unused.img \
  /mnt/hfs-data/task09160854/posix-contract

env -u HFS_DATA_REACTORS -u HFS_DATA_REACTOR_CPUS \
  -u HFS_OWNER_REACTOR_CPU -u HFS_REACTOR_PIN \
  -u HFS_BASELINE_TOTAL_REACTORS -u HFS_BASELINE_DATA_CPUS \
  -u HFS_BASELINE_APP_CPUS HFS_BDEV_NAME=Nvme0n1 \
  bash scripts/db/io_fast_path_smoke.sh \
  build/lib/libhfs.so config/hfs_nvme.json \
  /mnt/hfs-data/task09160854/unused.img \
  /mnt/hfs-data/task09160854/fast-path
```

验收输出必须同时包含 `POSIX CONTRACT OK` 和 `REQUEST-LOCAL FAST IO OK`。

## 6. 一次短性能 sanity（约 15 秒）

该样本只用于确认命令可运行和错误为零，不与旧基线做结论性比较：

```bash
RUN=/mnt/hfs-data/task09160854
env -u HFS_DATA_REACTORS -u HFS_DATA_REACTOR_CPUS \
  -u HFS_OWNER_REACTOR_CPU -u HFS_REACTOR_PIN \
  -u HFS_BASELINE_TOTAL_REACTORS -u HFS_BASELINE_DATA_CPUS \
  -u HFS_BASELINE_APP_CPUS \
  LD_PRELOAD=build/lib/libhfs.so \
  HFS_CONFIG_PATH=config/hfs_nvme.json HFS_BDEV_NAME=Nvme0n1 \
  HFS_FORMAT=1 HFS_AUTO_MKDIRS=/fio \
  HFS_LOCK_PATH=/mnt/hfs-data/task09160854/fio.lock \
  fio --name=auto-reactor-sanity --ioengine=psync --thread=1 \
  --numjobs=16 --iodepth=1 --bs=4k --size=64m --rw=randrw \
  --rwmixread=50 --filename=/hfs/fio/auto-reactor-sanity.dat \
  --direct=1 --time_based=1 --ramp_time=2 --runtime=5 \
  --group_reporting=1 --output="$RUN/auto-reactor-fio.json" \
  --output-format=json
```

验收：fio `error=0`；若有 trace，`trace_dropped=0` 且 `spdk_submit=spdk_complete`。记录 read/write IOPS、avg、p99 和 CPU，但不要据此宣布性能提升或锁定新基线。

## 7. 结果与停止条件

结果写入 `doc/task_result/task09160854_result.md`，只保留：在线 CPU、实际/期望拓扑、两项 smoke 状态、短测 IOPS/延迟/CPU、证据目录 `/mnt/hfs-data/task09160854`。

- 任一前置检查、编译、拓扑或 correctness 失败：立即停止并记录原因。
- 短测超时、fio 报错或 submit/complete 不闭合：立即停止，不补跑、不扩大范围。
- 本任务不上传或覆盖 VM 内 `spdk/` 源码。

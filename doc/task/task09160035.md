# HFS Shard-66 性能收口任务单（短测版）

## 0. 定位与预算（硬约束）

**唯一目标**：用 **≤10 分钟**性能测试完成 shard-66 两项杠杆的验证与默认值决策——拓扑（核心）与 adaptive wait（可选）。

- 性能样本：`ramp=5s + runtime=10s`；总样本 **≤12**；性能测试墙钟 **≤10 分钟**。
- 只测 **4K、jobs=32、shared-file**；不测 16K/64K、jobs=1/8、per-job-file、randrw50。
- **后端固定为 VM 内真实 NVMe**：`config/hfs_nvme.json`、`HFS_BDEV_NAME=Nvme0n1`、PCI BDF `0000:0b:00.0`；禁止用 Malloc/Aio 或其它后端替代，也不得在 NVMe 未绑定的环境出正式数字。
- correctness smoke 快速跑（不占性能预算）；不做矩阵、不做 5 次 median、不做 trace 归因。
- 禁止项：新优化方向（ticket/allocator/durability/fd/metadata/SPDK）、语义弱化、超预算补测、为数字重复扫描。

## 0.1 前置（不占性能预算）

1. 同步工作区到 VM，确认包含 **bug #89 修复**（poll 热路径原子写已门控），`make -B app lib`。
2. VM 环境检查：NVMe `0000:0b:00.0` 已绑定 `uio_pci_generic`、`vm.nr_hugepages=1024`、无残留 HFS/FIO 进程；VM 重启后先重新绑定设备再测试。
3. 快速 smoke：`scripts/db/posix_contract_test.sh`、`scripts/db/io_fast_path_smoke.sh`。
4. 预期量级：B 组（2 data reactor）4K randread 32j ≈100K、randwrite ≈82K；A 组（4 data）≈87K/68K。

## 1. 拓扑 A/B（核心，8 样本，约 4 分钟）

| 组 | 环境 |
|---|---|
| A 旧默认 | `HFS_BASELINE_TOTAL_REACTORS=5`、`DATA_CPUS=1,2,3,4`、`APP_CPUS=5-7` |
| B 推荐 | `HFS_BASELINE_TOTAL_REACTORS=3`、`DATA_CPUS=1,2`、`APP_CPUS=3-7` |

- 每组：4K randread 32j ×2 次 + 4K randwrite 32j ×2 次。
- **回归门**：A 组第一跑 randread 32j <70K → 立即停止排查（bug #89 同类回归），不得继续。
- **判定**：
  - 读写两个方向均 B ≥ A +10% → 采纳推荐拓扑，确认库默认（≤8 vCPU = 2 data reactor），更新文档；
  - B > A 但 <10% → 记录数据，按 ≥5% 决定是否写入推荐布局；
  - B ≤ A → 保持现状、记录证据，不再发散。

## 2. adaptive wait（可选，≤2 分钟，仅预算剩余时执行）

- futex（默认） vs `HFS_WAIT_MODE=adaptive HFS_WAIT_SPIN_US=1`，4K randread 32j 各 1 次。
- ≥5% IOPS 提升且 CPU 增幅 <10% → 采纳；否则保持 futex，仅保留开关。

## 3. 收口（≤5 分钟）

1. 结果只输出 `doc/task_result/task09160035_result.md`（小表：组/方向/IOPS/avg/p99/CPU + 判定 + 证据路径）。
2. 文档更新：
   - `doc/shard/hfs_posix_sync_boundary_topology_shard_plan.md`：状态头 + 实施记录追加本轮结论；
   - `doc/shard/shard_progress_memory.md`：shard-66 最终状态；
   - `AGENTS.md`：仅默认值/推荐布局变化时更新；
   - `doc/performance/hfs_shard66_baseline_v2.md`：记录锁定配置与实测增益。
3. 发现 bug → `doc/bug.md`；提交并合入 `main`。

## 4. 停止条件

1. 回归门触发且未定位 → 停止，不得进入后续对比。
2. A/B 无收益 → 记录即停，不补测、不换方向。
3. correctness 回归 → 回滚对应开关。
4. 预算用尽 → 停在当前阶段汇报，不自动扩大范围。

## 附录：命令模板

```bash
cd /root/code/HFS_BASE_SPDK

# A 组（旧默认）
HFS_BASELINE_RAMP_SECONDS=5 HFS_BASELINE_RUNTIME_SECONDS=10 HFS_BASELINE_RUNS=2 \
HFS_BASELINE_SIZE=256m HFS_BASELINE_MODELS="shared-file" HFS_BASELINE_BLOCK_SIZES="4k" \
HFS_BASELINE_OPERATIONS="randread randwrite" HFS_BASELINE_JOB_COUNTS="32" \
HFS_BASELINE_TOTAL_REACTORS=5 HFS_BASELINE_DATA_CPUS=1,2,3,4 HFS_BASELINE_APP_CPUS=5-7 \
bash scripts/db/shard66_baseline_v2.sh build/lib/libhfs.so config/hfs_nvme.json \
/mnt/hfs-data/shard66-focus-A

# B 组（推荐）
HFS_BASELINE_RAMP_SECONDS=5 HFS_BASELINE_RUNTIME_SECONDS=10 HFS_BASELINE_RUNS=2 \
HFS_BASELINE_SIZE=256m HFS_BASELINE_MODELS="shared-file" HFS_BASELINE_BLOCK_SIZES="4k" \
HFS_BASELINE_OPERATIONS="randread randwrite" HFS_BASELINE_JOB_COUNTS="32" \
HFS_BASELINE_TOTAL_REACTORS=3 HFS_BASELINE_DATA_CPUS=1,2 HFS_BASELINE_APP_CPUS=3-7 \
bash scripts/db/shard66_baseline_v2.sh build/lib/libhfs.so config/hfs_nvme.json \
/mnt/hfs-data/shard66-focus-B

export HFS_WAIT_MODE=adaptive HFS_WAIT_SPIN_US=1
```

汇总：`python3 scripts/db/shard66_summary.py <out-dir>`，只看 4K 行。
